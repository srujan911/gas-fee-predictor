Feature Importance Explanation
===========================
Feature importance values show the relative importance of each feature
in making predictions. Values are on a scale from 0 to 1, where higher
values indicate greater importance. The sum of all importance values equals 1.
These are NOT the actual values of the features but their relative importance
in the prediction model.
